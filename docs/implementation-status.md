## Current product boundary

The server has conditional HTTP routes for account auth, device enrollment and a private synthetic message test. It can issue a writer-fenced synthetic execution grant and durably acknowledge device evidence only under explicit runtime/account/recipient allowlists, one-shot phone readiness for the exact recipient digest, and writer dispatch authority. The Android authenticated socket has a manually armed, one-attempt synthetic grant and radio path with durable event replay and a pre-radio one-use journal boundary. Local build/database tests, Samsung authenticated WSS/pairing probes, and one authorized Samsung SMS with positive sent/delivery callbacks passed. This establishes one controlled carrier pilot result, not generalized delivery reliability. SMTP transport and a durable verification outbox are implemented, but no live verification email has been sent. A Compose migration runner applies numbered SQL under an advisory lock and checksum ledger; a disposable logical restore rehearsal is in review, but production TLS and off-site recovery remain open. Sealed content, independent security review, public deployment, customer payment flows, and geographic redundancy remain unimplemented.
