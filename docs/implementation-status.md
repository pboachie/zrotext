## Current product boundary

The server's HTTP routes do not yet expose customer auth, messages, device enrollment, or dispatch. The new auth, enrollment and delivery-store libraries are internal. A Compose migration runner now applies numbered SQL under an advisory lock and checksum ledger; its production TLS and restore path is not yet implemented. The Android adapter contains an internal radio boundary but the UI/socket do not call it, and no SMS has been sent or received. Sealed content, independent security review, public deployment, payment integration, and geographic redundancy remain unimplemented.
