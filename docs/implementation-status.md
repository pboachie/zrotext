## Current product boundary

The server's HTTP routes do not yet expose customer auth, messages, device enrollment, or dispatch. The new auth and delivery-store libraries are internal, and migrations 002–003 have only been exercised in an isolated test schema; no production migration runner exists. The Android adapter contains an internal radio boundary but the UI/socket do not call it, and no SMS has been sent or received. Sealed content, independent security review, public deployment, payment integration, and geographic redundancy remain unimplemented.
