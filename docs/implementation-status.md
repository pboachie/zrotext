## Current product boundary

The server has conditional HTTP routes for account auth, device enrollment and a private synthetic message test. It can issue a writer-fenced synthetic execution grant and durably acknowledge device evidence only under explicit runtime/account/recipient allowlists, one-shot phone readiness for the exact recipient digest, and writer dispatch authority. The Android authenticated socket now has a manually armed, one-attempt synthetic grant and radio path with durable event replay and a pre-radio one-use journal boundary. It has passed local build/database tests and the Samsung app launch, but no live WSS or carrier SMS has run; no SMS has been sent or received. SMTP transport and a durable verification outbox are implemented, but no live verification email has been sent. A Compose migration runner applies numbered SQL under an advisory lock and checksum ledger; its production TLS and restore path is not yet implemented. Sealed content, independent security review, public deployment, payment integration, and geographic redundancy remain unimplemented.

## Current PR #21 safety review

The Android alpha stream, radio handoff and delivery timeout remain in open PR #21. The delivery status parser now uses the SMS PDU format before accepting a received status. Android persists one callback_conflict event when contradictory callbacks follow a writer-acknowledged intent; the writer records unknown and retains the no-retry fence, including after an earlier delivered state. Local Rust workspace tests, Android unit tests, Android lint and Rust clippy pass. No live WSS or SMS has run.

A true writer acknowledgement followed by a pre-radio refusal remains conservatively fenced even when the phone has local no-call evidence. A very late conflict for a completed attempt can need manual reconciliation when another attempt already holds that device active fence. These are open pilot limits; the controlled one-send test is not armed.
