## Current product boundary

The server now has conditional HTTP routes for account auth and device enrollment. It does not expose message acceptance, authenticated device sockets, dispatch or inbound SMS. SMTP transport is implemented but no live verification email has been sent. A Compose migration runner applies numbered SQL under an advisory lock and checksum ledger; its production TLS and restore path is not yet implemented. The Android radio adapter remains internal and the UI/socket do not call it; no SMS has been sent or received. Sealed content, independent security review, public deployment, payment integration, and geographic redundancy remain unimplemented.
