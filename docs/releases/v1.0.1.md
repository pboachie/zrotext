# ZROtext 1.0.1 candidate

The Android candidate uses version name `1.0.1` and version code `15`, following
`1.0.0` / code `14`.

The launcher now uses the existing lime-and-dark-green ZROtext mark instead of
the generic Android icon. Adaptive launcher masks and Android themed icons are
supported. Account, device keys, permissions and messaging behavior are unchanged.

Source and local verification do not establish signed distribution, Google Play
approval or carrier delivery. Artifact identities and acceptance belong to the
reviewed release and its receipts.
