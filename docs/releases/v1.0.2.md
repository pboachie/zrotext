# ZROtext 1.0.2 candidate

The Android candidate uses version name `1.0.2` and version code `16`, following
`1.0.1` / code `15`.

After a conclusively failed controlled test, the phone can review and approve
one new test for the selected SIM and controlled recipient. The new approval
requires acknowledged failure evidence and refuses ambiguous or conflicting
outcomes. It preserves the original one-use marker, attempt history, pairing
and keys, and never retries the previous message automatically.

Approvals expire after five minutes and are consumed before radio reservation.
Session retirement is checked again after blocking approval and suppression
work. Approval history is retained with a lifetime limit of 64 entries.

The app package, SDK policy and permissions are unchanged. Source and automated
checks do not establish signed distribution, Google Play approval or carrier
delivery. Those require separate artifact and device acceptance.
