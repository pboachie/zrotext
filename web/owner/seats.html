Device-status observers

Devices and sign in

Observers sign in with their own verified email and can view device status only. They cannot send or read messages, manage devices or API keys, see billing or exports, invite others, or change owner settings.

Invite an observer

Inviting an observer grants lasting read access, so confirm it with your password (and your authenticator or recovery code if you use one). The invitation token is shown once. Deliver it to one person out of band; it expires in seven days, works once, and is bound to the invited address. This page never says whether the address already has an account; if the address cannot accept the invitation, only the person holding the token finds out when they try.

    Observer seats

    Removing a seat signs it out everywhere, cancels its outstanding credentials immediately, and deletes the observer's account so the address is free again. A removed seat cannot be restored; invite the address again to start over. If the account could not be deleted, the seat is still removed but the entry says the address stays occupied.
