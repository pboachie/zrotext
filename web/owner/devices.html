    Updates and status details

    Fleet observations are loading.

    While this tab is visible, device and message updates arrive over a live same-origin event stream and lists refresh within a few seconds of a server-side change. If that stream cannot connect, updates fall back to a 15-second snapshot refresh. A list pauses while you browse older entries, focus a row, or open message events. Use Refresh to return to its latest entries.

    Approval permits a phone to connect. A displayed authenticated socket lease is a server observation that can lag a dropped connection by up to 90 seconds. It does not prove SMS permission, SIM service, or dispatch readiness. Check the gateway app on the phone before a controlled test.

    Pending counts accepted, queued and claimed messages; in flight counts submitting and submitted messages. These server states can include work awaiting expiry reconciliation. Counts stop at 1,000+ per category. Check the snapshot time and message timeline for unknown or final outcomes.

    Android reports describe selected SIM availability, SMS permission and airplane mode at the shown receipt time. Fresh reports explain local blockers to check on the phone. Saved reports become historical after the freshness window, even with automatic refresh paused. No reported blockers does not prove carrier readiness or delivery. Check the message timeline for actual callback evidence.

        After pairing: permissions, SIM and connection
        1. On the phone, review the gateway app's permission requests. If you denied a required permission, open the app's Android settings and choose whether to grant it; then return to the app.
        2. In the gateway app, select the active physical SIM you intend to use. Check airplane mode and network service on the phone.
        3. Open SMS lines, create the browser approval key and review the phone's declaration before activating a line.
        4. Check device status. Connected status alone does not prove that the phone can send or that a message was delivered.

        Pairing adds a phone to this account. Permission choices, line approval and consent are separate steps; pairing does not authorize a real SMS test.

        Opt-out review

        Record your decision after reviewing a possible SMS withdrawal through your consent process. Both decisions leave the recipient blocked; neither establishes consent or resumes sending. Decisions are permanent. Only recipient metadata is shown, never SMS content.

          Requests received elsewhere

          Record an opt-out received by phone, email or another channel. This blocks new messages and cancels queued messages before they are authorized for sending. Sending already in progress may still finish.

          No message content or free-text notes are collected. There is no manual unblock button; recording this request does not establish new consent.

                    Why this security step?

                    Line activations are approved with a signing key that stays in this browser. The server stores only its public key. Clearing this browser's site data removes the key; revoke it and create a new one if that happens.
