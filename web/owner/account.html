    Account · your data

    Export or erase account data

    Download the server takeout

    Download private JSON parts to your own device. Each part contains the server's original responses, including message content and contacts where available. Keep every part somewhere safe.

    Sealed content stays encrypted. This is not a key backup or a database backup. Retention may already have removed content; some sections contain only metadata. Line setup includes at most 16 registrations and 16 exchanges without further pages. Data can change between requests.

    Each step reads at most eight pages, with an 8 MiB page limit and a 32 MiB part limit. Continue until all exposed pages have been retrieved. Responses may repeat completed families; parts are raw pages, not a deduplicated record list. Export stops at 4,096 distinct continuation cursors; contact the operator if that safety limit prevents completion. Leaving this page clears continuation and download links.

    Erase this account on this server

    This permanently deletes the account and its invited observer users in one transaction if the server permits it. Line identities, immutable trust or audit history and other retained references can block the whole request. Nothing is deleted when the server reports blockers.

    Erasure does not cancel external subscriptions, release carrier identities, delete external copies, or rewrite backups, replicas or WAL archives. Export first if you need a copy.

    An account-ID record may remain for the app's database lifetime to prevent identity reuse. It contains your account ID, deleted state, and a version counter. The receipt lists this retained identity record and shared request-budget counters when present.
