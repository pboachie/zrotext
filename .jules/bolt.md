## 2024-06-25 - [Optimize JSON string parser]
**Learning:** In JavaScript string/JSON parsing loops, using `indexOf` and `slice` is significantly faster than character-by-character iteration. Ensure the search index advances past the current character to prevent infinite loops. When searching for JSON quotes with `indexOf('"')`, correctly identify escaped quotes by counting backslashes backwards from the quote index (an odd count means it's escaped). Do not use raw string lengths (e.g., `quote - start`) to bound string parsing limits, as valid strings with escaped characters will have a raw length greater than their parsed length, leading to functional regressions.
**Action:** When implementing custom JSON parsers, prioritize built-in string methods like `indexOf` for token discovery instead of character iteration.
